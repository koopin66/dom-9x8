# Дом 9 × 8 м с террасой

[Открыть проект](https://koopin66.github.io/dom-9x8/)

Планы этажей, разрез, три вида фасадов и интерактивная 3D-модель. Двухэтажная часть 5075 мм, крыло кухни-гостиной 3925 мм. Внутренние помещения по экспликации 81,02 м². Терраса 7,85 м² и крыльцо 1,79 м² указаны отдельно. Перепад основания под террасой 50 мм.
