# Редактор дома

[Открыть проект](https://koopin66.github.io/dom-9x8/)

Исходный вариант — дом 9000 × 8000 мм с террасой и перепадом основания 50 мм.

Изменения размеров отражаются одновременно в SVG-чертежах и в Three.js-модели. Можно редактировать габариты, высоты и кровлю, толщину стен, положение и длину перегородок, размеры и расположение окон и дверей, лестницу и крыльцо. Новые перегородки, окна и двери добавляются кнопками редактора.

При изменении габаритов план масштабируется пропорционально, включая толщины стен и ширину проёмов. Отдельные размеры можно уточнить после изменения габаритов. Проверяются границы, высоты и пересечения проёмов. Стыки произвольно перемещённых перегородок нужно проверять на плане. Это эскизный редактор, конструктивные расчёты выполняются отдельно.

Наружный фасад выступает на 121 мм от контура стен с каждой внешней стороны, включая стены у террасы. Параметр «Выступ фасада наружу, мм» находится в разделе «Дом и крыша → Высоты, кровля и основание». Внутренние размеры помещений сохраняются.

Толщина всех окон и остеклённой двери — 70 мм. Оконные рамы расположены по центру наружного слоя стен 121 мм: отступ от каждой грани слоя составляет 25,5 мм. План и 3D используют одинаковое положение окон. Выберите окно и измените «Толщина окна, мм» (20–300 мм), чтобы поменять глубину рамы в 3D. Новые окна получают толщину 70 мм. Старые JSON и сохранённые варианты автоматически получают новые параметры без сброса остальных размеров.

## Сохранение

Изменения автоматически сохраняются в localStorage этого браузера. Кнопка «Скачать проект» экспортирует JSON для переноса на другое устройство, резервной копии или передачи другому человеку. «Открыть JSON» восстанавливает модель. Изменения пользователя не отправляются на GitHub и не заменяют общедоступный исходный проект. Поддерживаются отмена и повтор действий. Текущий чертёж экспортируется в SVG.

## Файлы

- `editor-model.js` — схема, проверка и общая геометрия в миллиметрах.
- `editor-drawings.js` — планы, фасады, разрез и размерные надписи.
- `editor-3d.js` — обновляемая 3D-сцена с выбором объектов.
- `editor.js` — панель параметров, история, автосохранение, импорт и экспорт.
- `index.html` и `dom-9x8.html` — одинаковые точки входа.
- `vendor/` — Three.js r128 и OrbitControls с лицензией MIT.
- `drawings/` — исходные листы для сравнения.

Сборка не требуется. Для локального запуска можно использовать `python -m http.server 8080`. Проверка геометрии и JSON — `node editor-model.test.cjs` и `node editor-facade.test.cjs`.
