# Дом 9 × 8 с террасой

Эскизный проект жилого дома, собранный по ручным эскизам (план 1 этажа, план 2 этажа, западный фасад) и планировке из коммерческого предложения.

**Открыть проект:** https://koopin66.github.io/dom-9x9/

Весь проект — одна страница [`index.html`](index.html) (её исходник для артефакта Claude — [`dom-9x8.html`](dom-9x8.html)). Можно открыть и локально в браузере; нужен интернет для шрифтов и 3D-модели.

## Что внутри

- План 1 этажа и план 2 этажа (мансарда) с мебелью, дверями, лестницей и размерными цепочками
- Фасады: западный, восточный, южный, северный — с отметками высот
- Разрез 1–1 по лестнице
- Объёмная 3D-модель (вращение, режимы «без кровли», «1 этаж», «2 этаж»)
- Экспликация помещений, спецификация окон и дверей
- Сверка размеров с эскизом и КП, список допущений

## Основные параметры

| Параметр | Значение |
|---|---|
| Габариты | 9000 × 8000 мм |
| Объёмы | двухэтажный 5500 + одноэтажный 3500 |
| Высота | 6250 (двухэтажный), 5300 (одноэтажный) от земли |
| Цоколь | 300; площадка террасы на 50 ниже площадки дома (−0,050) |
| Кровля | односкатные, 15° и 20°, свесы 700 |
| Стены / перегородки / кровля | 200 / 100 / 250 |
| Общая площадь | 88,71 м² + терраса 7,35 м² |

Глубина 8000 получена из эскизного 9000 за счёт зоны холла (3500 → 2500), поэтому площади с эскиза (6,25 · 5,25 · 11,25 · 19,25 · 16,5) в осях сохранены; чистые площади приведены в экспликации.
